# Sat-NS — платежи ЖК (MVP)

PWA для экосистемы SAT: приложение жителя (`#/app`) и кабинет управляющей компании (`#/admin`). Все данные моковые и хранятся в `localStorage` браузера.

## Запуск

```bash
npm install
npm run dev                                       # http://localhost:5173
npm run build && npm run preview                  # прод-сборка + service worker
node --experimental-strip-types src/model.check.ts  # самопроверка расчётов
```

## Деплой на Vercel через GitHub

1. Запушьте репозиторий на GitHub.
2. Vercel → **Add New → Project** → выберите репозиторий.
3. Если эта папка (`app/`) лежит внутри репозитория, укажите **Root Directory = `app`**. Остальное возьмётся из `vercel.json` (Vite, `npm run build`, `dist`).
4. Deploy. Каждый пуш в `main` даёт прод-деплой, пуш в другие ветки — превью.

## PWA

- `public/manifest.webmanifest`: стартовый экран `#/app`, иконки any и maskable, ярлыки «Оплатить», «Соседи», «Кабинет УК».
- `public/sw.js`: сначала сеть, при ошибке кэш. Оболочка приложения кэшируется при установке, поэтому оно открывается офлайн. При изменении стратегии кэширования поднимите `VERSION`.
- `vercel.json`: `sw.js`, `index.html` и манифест не кэшируются, чтобы обновления доходили сразу; хэшированные `assets/` кэшируются навсегда.
- **Установка:** на Android Chrome предложит «Установить приложение». На iPhone: Safari → «Поделиться» → «На экран Домой». Push-уведомления на iOS работают только из установленного приложения (iOS 16.4+).

## Структура

| Файл | Что внутри |
|------|-----------|
| `src/model.ts` | Генерация моков и все расчёты: начисления, долги, пени, серии, баллы, представители подъездов |
| `src/store.ts` | Состояние демо в localStorage, синхронизация между вкладками |
| `src/Resident.tsx` | Приложение жителя |
| `src/Neighbors.tsx` | Соседи: старший по подъезду, чат, реакции |
| `src/Admin.tsx`, `src/AdminMobile.tsx`, `src/adminData.tsx` | Кабинет УК: десктоп, телефон, общие данные |
| `docs/brand-guidelines.md`, `PRODUCT.md` | Бренд и продуктовые принципы |
